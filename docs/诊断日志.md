# 诊断日志

> 说明 sp_ImeHook 的常开诊断日志：热路径只写定长环形缓冲，落盘与排空在后台。
> 注入链路见 [模块实现机理.md](模块实现机理.md)。
> 最后更新：2026-11-09

---

## 1. 一句话结论

日志**始终开启**，无开关。热路径只做：两次单调时钟取样 + 无堆分配抄键/候选 + 短暂持锁写入环形缓冲；
落盘统一在模块进程（`files/logs/imehook-yyyy-MM-dd.log`），按天分隔，保留近 7 天。
模块不申请 `INTERNET`，不联网上传。

---

## 2. 为什么没有开关

按键事件的热路径成本是微秒级定长拷贝，不会造成可感卡顿；关掉会丢掉「钩子有没有打中 /
自定义表有没有命中」的直接证据。凡是不会带来严重性能问题的诊断信息都常开。

---

## 3. 结构

```
模块 App（lpt.imehook）
  SettingsUiState.apply / restore / restart
    └─ LogSink.append  →  [app] …                 ← 本进程直接写

目标进程（豆包输入法）
  expandHook（输入线程）
    └─ 定长事件入环形缓冲（互斥锁，无 I/O）
         │
         │  后台线程每 2 秒 nativeDrainDiag（锁内只拷贝）
         ▼
  HookEntry
    ├─ [baseline] / [error] 安装、配置、异常
    └─ 排空后的按键行
         │  ContentProvider.call("appendLog") unstable
         ▼
模块 App
  LogSink → files/logs/imehook-yyyy-MM-dd.log（超 7 天删除）
         │
         ▼
设置页：选日期 → 查看 / 导出当天 / 清空全部
```

---

## 4. 行类型

| 前缀 | 来源 | 用途 |
|---|---|---|
| `[app]` | 设置页应用/还原/重启 | 核对 ini→扁平表→publish 是否走出 |
| `[baseline]` | 目标进程 HookEntry | 装载、配置下发、延迟装钩、重启 |
| `[error]` | 目标进程异常路径 | so 加载 / 装钩 / 配置失败 |
| `t=…` | native 按键事件 | 单次 expand 的键、走向、候选、耗时 |
| `dropped=N` | 排空时缓冲曾溢出 | 漏采条数（覆盖的是最旧事件） |

每行落盘时由 `LogSink` 加本地墙钟 `HH:mm:ss.SSS`。

### 4.1 `[app]` 样例

```
[app] apply mode=2 scheme=流珀天 tableEntries=647 flatBytes=8821
[app] apply mode=1 slot=6
[app] restore mode=0
[app] restart requested exit=1731139200123
```

### 4.2 `[baseline]` 要点

```
[baseline] init proc=… versionCode=… nativeLoaded=… installedNow=… installed=… how=… table=… converts=…
[baseline] config applied proc=… mode=… tableBytes=… tableEntries=… src=provider|cache …
[baseline] hook installed after libshell proc=… how=version-table|signature-scan …
```

`how=unsupported` 或 `installed=0` 且长期无 `t=` 行 → 没打中钩点。
`[app] apply` 的 `tableEntries` 与随后 `[baseline] config applied` 的 `tableEntries` 应对得上；对不上就是 ini→hook 灌表链路问题。

### 4.3 按键行

```
t=360612383537226 d=43437 m=2 s=6 k=er r=1 x=2 v=ou
```

| 字段 | 含义 |
|---|---|
| `t` | `CLOCK_MONOTONIC` 纳秒 |
| `d` | 本次调用耗时 ns（含目标自身展开） |
| `m` | 0 直通 / 1 槽位 / 2 自定义 |
| `s` | 当前槽位 |
| `k` | 键（最多 2 ASCII） |
| `r` | 候选数 |
| `x` | 0 直通 / 1 槽位 / 2 自定义命中 / 3 未命中空返回 |
| `v` | 展开拼音（逗号分隔，最多 8 个，整体 ≤96 字节） |

同一物理按键常成对出现（目标两条展开路径），时间差 &lt; 1ms，不是重复按键。

---

## 5. 文件

```
/data/data/lpt.imehook/files/logs/imehook-2026-11-09.log
```

- 按天一个文件；写入时删除超过 7 个自然日的旧文件；
- 「查看 / 导出」针对所选日期的**整天**内容；
- 「清空」删除全部按天文件（及旧版 `imehook.log` / `.1` 残留）。

---

## 6. 排查速查

| 现象 | 日志特征 |
|---|---|
| 钩子没打上 | `installedNow=false` / `how=unsupported`，且无 `t=` 行 |
| 配置没下发 | 有 `[app] apply` 无对应 `[baseline] config applied`，或 `src=cache` 且内容旧 |
| ini 解析/灌表错 | `[app] tableEntries` ≠ baseline `tableEntries`，或 `k=` 命中但 `v=` 与方案不符 |
| 某键未覆盖 | `x=3` |
| 模式未生效 | 全是 `x=0` 且 baseline `mode=0` |

---

## 7. 隐私与边界

- 按键与拼音音节会写入私有目录；导出需用户主动选位置（SAF）；
- 模块进程未启动时推送失败会静默丢弃，不影响输入；
- 目标进程被杀时未排空缓冲会丢失（重启前会尽量排空一次）。
